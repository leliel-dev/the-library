# Structure
Each document gets its own directory in the `src` directory. The metadata file in each writeup's directory contains data that will be used to display the writeup on the site. The rest should be mostly obvious. See also \[the thing\]

# Getting started
The flake contains a devshell with the tools required, but not the fonts. It is proving difficult to keep an up to date list of required fonts, so consult templates primarily, but some relevant packages in nixpkgs include:
- `inter`
- `ibm-plex`
- `tex-gyre-math.pagella`
- `gyre-fonts`
- `hanken-grotesk`
- `newcomputermodern`
- `corefonts`
